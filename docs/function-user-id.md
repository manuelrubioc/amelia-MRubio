# Function: User ID

This function retrieves user identification details, including their affiliation and contact information.

## Configuration

| Setting | Value |
|---------|-------|
| Action Type | `CONSUME_WS_ACTION` |
| WS Action | `userID` |
| Requires Confirmation | No |

## Output Parameters

| Name | Description |
|------|-------------|
| `actualizationDate` | The date when the user's information was last updated. |
| `affiliationChannel` | The channel through which the user was affiliated or registered. |
| `affiliationDate` | The date when the user was initially affiliated or registered. |
| `cardNumber` | The user's card number associated with their account. |
| `operatorCode` | The code representing the operator handling the user's account. |
| `phoneNumber` | The user's contact phone number. |
| `uniqueCode` | A unique code identifying the user within the system. |
